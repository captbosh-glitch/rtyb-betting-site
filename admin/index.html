Import CSV

Choose a file or paste rows. Columns (any order, header row required): date, away, home, segment, ats_away, ats_home, ml_away, ml_home, total, plus optional ats_away_price, ats_home_price, over_price, under_price (blank = –110). A matchup column like “LV @ NY” works instead of away/home. Missing date or segment uses what’s selected above. Teams match by name, city, nickname or abbreviation. Download a template
